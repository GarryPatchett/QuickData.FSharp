# QuickData.FSharp

This is the public repository for the QuickData.FSharp packages:
- [QuickData.Core.FSharp](https://www.nuget.org/packages/QuickData.Core.FSharp) - contains core elements used in the other QuickData.FSharp packages.
- [QuickData.Characters.FSharp](https://www.nuget.org/packages/QuickData.Characters.FSharp) - for creating sequences of characters.
- [QuickData.Digits.FSharp](https://www.nuget.org/packages/QuickData.Digits.FSharp) - for creating sequences of digits.
- [QuickData.Numbers.FSharp](https://www.nuget.org/packages/QuickData.Numbers.FSharp) - for creating sequences of numbers with different 'shapes'.
- [QuickData.Words.FSharp](https://www.nuget.org/packages/QuickData.Words.FSharp) - for creating sequences of English words.

This repo currently only includes images for use in the README files and the release notes for each package.

Please visit the links above to see more information about these packages - documentation is available in the README and via Intellisense.

Feel free to add issues for, make suggestions about, or ask questions regarding, the QuickData.FSharp packages here.
